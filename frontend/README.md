# Frontend

React, TypeScript, and Vite application with React Router and Redux Toolkit configured.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

## Structure

- `src/app/store.ts` - Redux store
- `src/app/hooks.ts` - typed Redux hooks
- `src/App.tsx` - route definitions and starter pages
- `src/main.tsx` - application providers and entry point
